# README visuals

The main README uses the existing [OpenCrate logo](../branding/opencrate-logo.png),
a vector download button and three real screenshots of the installed OpenCrate
0.1.0 Windows app in English:

- `lighting.jpg`: effect preview, color, brightness and animation speed.
- `fans.jpg`: detected fans, cooling controls and the current CPU fan curve.
- `power.jpg`: the Balanced Windows power plan and processor settings.

The JPEG files are unedited window captures, not mockups. Values show the state
of the machine at capture time; supported controls vary by hardware. The app's
language was changed temporarily for the captures and then restored. No lighting,
fan or power settings were applied while taking them.

When refreshing the images, capture only the OpenCrate window and review it for
personal data, custom plan names and device identifiers before publishing. Keep
the README's version caption current. The source privacy check allowlists these
three exact image paths.
