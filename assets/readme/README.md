# README visuals

The main README uses the existing [OpenCrate logo](../branding/opencrate-logo.png),
a vector download button and `opencrate-lighting.png`, a real screenshot supplied
by the project owner on 2026-09-07. It shows the English Lighting page with a
static red effect selected.

The screenshot keeps its original dimensions and pixels. Only PNG compression
and removal of nonessential metadata were applied; no content was retouched.
Available controls vary by hardware. Review replacement screenshots for personal
data before publishing. The source privacy check allowlists this exact image path.
