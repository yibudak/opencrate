# Community code of conduct

Treat contributors and users with respect. Welcome people with different levels
of experience, backgrounds and viewpoints. Discuss ideas and code with specific,
constructive feedback, and accept good-faith corrections.

Harassment, threats, discriminatory language, sexualized conduct, personal attacks,
and disclosure of another person's private information are not acceptable. Do not
spam discussions or pressure people to share personal data or test unsafe hardware
changes. These expectations apply to issues, pull requests and project discussions.

Maintainers may edit or remove inappropriate content, close disruptive discussions,
or restrict participation. Use GitHub's report-abuse tools for abusive content and
avoid repeating private information in a public report. Raise technical security
concerns through the private process in [SECURITY.md](SECURITY.md).
